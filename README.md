Arabic Sign Language Translation System

Overview

An integrated computer vision and deep learning system designed to translate Arabic Sign Language gestures into text and speech.

Key Features

* Sign language gesture recognition.
* Translation of recognized signs into text.
* Audio output for translated text.
* Facial and eyebrow feature analysis, where applicable.

Project Details

* Domain: Computer Vision and Deep Learning
* Language: Arabic Sign Language
* Tools: Google Colab and MATLAB, along with the other tools used in the project.
